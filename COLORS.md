# Blocklogic Studio — Color Tokens

## CSS Variables (recommended)

```css
:root {
  /* Primary */
  --bl-blue:        #3B82F6;
  --bl-slate:       #0F172A;
  --bl-white:       #F8FAFC;

  /* Secondary */
  --bl-cyan:        #22D3EE;
  --bl-amber:       #F59E0B;
  --bl-red:         #EF4444;
  --bl-gray:        #64748B;

  /* Surfaces */
  --bl-surface:     #1E293B;
  --bl-surface-2:   #334155;
}
```

## Minecraft § Color Mapping (for in-game text)

| Meaning     | Code | Approx |
|-------------|------|--------|
| Primary     | §9   | Blue   |
| Success/Live| §b   | Aqua   |
| Warning     | §6   | Gold   |
| Error       | §c   | Red    |
| Muted       | §7   | Gray   |
| Highlight   | §f   | White  |

Example:
```
§9[Blocklogic] §fCarrierCore §7v2.1 loaded
§bTower online §7· §cDC overheat
```
