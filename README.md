## 5. Logo Direction

### Concept
A minimal geometric mark that suggests both **blocks** and **logic/circuits**.

**Preferred directions:**
1. Abstract interlocking blocks forming an “L” or circuit node
2. Clean monogram “BL” with subtle block geometry
3. A single precise geometric block with a signal/circuit line running through it

**Style rules:**
- Flat or very subtle depth (no heavy skeuomorphism)
- Works at 16×16 (pack icons) and large sizes
- Looks good in pure white and pure black
- No gradients required for the core mark

### Logo Variants Needed
- Full wordmark: **Blocklogic Studio**
- Short wordmark: **Blocklogic**
- Icon only (square)
- Pack icon style (Minecraft 128×128 / 256×256)

---

## 6. Voice & Tone

| Do | Don’t |
|----|-------|
| Precise, technical, confident | Hype-y or clickbait |
| Clear and direct | Overly casual slang |
| Systems-focused language | Vague “epic addon” language |
| Honest about limitations | Overpromise features |

**Example:**
> CarrierCore simulates multi-carrier cellular networks with real outage logic, dual-SIM support, and microwave backhaul.

Not:
> The most epic phone addon ever made!!! 🔥🔥

---

## 7. Project Naming Convention

- Studio name + project name when needed: `Blocklogic CarrierCore`
- Internal repos: `carriercore`, `branding`, etc. (lowercase, hyphenated)
- Pack names inside Minecraft: `CarrierCore Behavior Pack`, `CarrierCore Resource Pack`

---

## 8. Pack Icon Guidelines

- Square, high contrast
- Readable at small sizes
- Prefer the studio icon or a clean project-specific symbol
- Avoid cluttered scenes
- Consistent border treatment across all studio packs (optional subtle frame)
